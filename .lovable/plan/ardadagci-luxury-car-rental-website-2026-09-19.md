# ARDADAGCI Luxury Car Rental Website

## Goal
Build a premium, responsive Dubai luxury-car-rental website with a clean white editorial direction, refined spacing, strong vehicle photography, smooth motion, and direct WhatsApp conversion paths.

## Pages and navigation
- Add a shared sticky header with the ARDADAGCI wordmark, desktop navigation, mobile menu, and prominent Book Now action.
- Create distinct pages for Home, Fleet, About, TikTok, Reviews, Contact, Booking, and individual vehicle details.
- Add a polished footer with navigation, contact details, social links, and legal copy.

## Home page
- Create an editorial opening view with a large left-aligned headline and a Lamborghini/Dubai skyline composition.
- Add Explore Fleet and WhatsApp Booking actions plus Free Delivery, Full Insurance, and 24/7 Support highlights.
- Add four featured vehicles with photography, performance specifications, pricing, and Rent Now actions.
- Add founder storytelling with portrait, bio, signature treatment, and business statistics.
- Add a TikTok phone showcase, selected customer reviews, and a large WhatsApp booking section.

## Fleet and booking experience
- Add a searchable/filterable fleet listing with vehicle classes and pricing.
- Add individual vehicle pages with gallery, specifications, rental highlights, related vehicles, and booking actions.
- Add a responsive booking form covering vehicle, dates, contact details, delivery location, and notes.
- Generate prefilled WhatsApp messages from both vehicle pages and the completed booking form.
- Use clearly marked sample contact details where real business details were not supplied.

## Visual system and interaction
- Define an original monochrome editorial design system with a restrained warm accent, premium typography, sharp imagery, compact controls, and subtle borders.
- Generate a cohesive set of luxury vehicle, founder, and Dubai imagery for the site.
- Add restrained reveal, image, navigation, and phone-preview motion with reduced-motion support.
- Ensure the layout works cleanly across mobile, tablet, desktop, and wide screens.

## Technical details
- Implement in the project’s supported TanStack Start, React, TypeScript, Tailwind CSS, and shadcn/ui stack, matching the requested Next.js user experience.
- Keep shared content and vehicle data centralized so listing, detail, and booking views stay consistent.
- Add unique titles, descriptions, Open Graph metadata, and Twitter card metadata for every content page.
- Validate the final experience in the running preview at desktop and mobile sizes, including navigation, filters, detail links, booking submission, and WhatsApp URLs.
