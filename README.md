# Ardadagci Luxury Drive

Build a premium luxury website for ARDADAGCI Dubai Car Rental. Use a clean white editorial layout inspired by Apple and Porsche. Create a sticky navbar with logo left and Home, Fleet, About, TikTok, Reviews, Contact plus a Book Now button. Build a hero with a large left-aligned headline, two CTA buttons (Explore Fleet and WhatsApp Booking), three feature icons (Free Delivery, Full Insurance, 24/7 Support), and a large Lamborghini image with Dubai skyline on the right. Add a Featured Fleet section with four premium cards showing image, car name, horsepower, transmission, 0-100 time, daily price and Rent Now button. Add an About Arda section with founder image, bio, signature and statistics. Add a TikTok showcase with phone mockup and content previews. Add customer reviews, a large WhatsApp booking CTA and a premium footer. Include Fleet listing, single car detail pages, booking form and WhatsApp booking integration. Use Next.js, TypeScript, Tailwind, shadcn/ui, smooth animations and make it fully responsive. The design should feel almost identical to a premium editorial luxury car rental landing page with lots of whitespace and refined spacing.
